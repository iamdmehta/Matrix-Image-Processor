## Matrix-Based Image Processing in C

A C-based image processing project that implements fundamental image manipulation algorithms from scratch using a 64 × 64 grayscale `.pgm` image. The project focuses on understanding how digital images are represented as matrices of pixel intensities and how mathematical operations on these matrices enable common image processing tasks.

Implemented features include brightness adjustment, image rotation, image blurring, edge detection using the Sobel operator, and lossless image compression using Run Length Encoding. The project emphasizes the underlying algorithms and matrix transformations rather than relying on external image processing libraries.

Although the implementation is limited to grayscale images, the same principles extend naturally to colour image processing by operating on individual colour channels.
